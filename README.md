# BODY OS — личное PWA для тренировок, питания и ухода

Работает без сервера, аккаунта и платных сервисов. Все данные хранятся только в браузере вашего телефона.

## Запуск на компьютере
1. Установите Python (python.org) или откройте папку в VS Code.
2. В папке проекта выполните: `python -m http.server 8080`
3. Откройте http://localhost:8080

## Публикация на GitHub Pages
1. Создайте аккаунт на github.com и новый публичный репозиторий `body-os`.
2. Нажмите «Add file → Upload files», перетащите ВСЕ файлы из папки (не саму папку) и нажмите Commit.
3. Откройте Settings → Pages. В «Source» выберите «Deploy from a branch», ветка `main`, папка `/ (root)`, Save.
4. Через 1–2 минуты ссылка появится вверху страницы: `https://ВАШ-ЛОГИН.github.io/body-os/`. Пути в проекте относительные, поэтому всё работает в подпапке.

## Установка на телефон
- **Android (Chrome):** откройте ссылку → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте ссылку → «Поделиться» → «На экран Домой».

## Важно
- Резервная копия: Ещё → Настройки → «Скачать резервную копию». Делайте раз в неделю: если очистить данные браузера, записи пропадут.
- Обновления: при изменении файлов увеличьте номер `V` в `sw.js` (например `bodyos-v2`). Данные при этом сохраняются.
- Отчёт для ChatGPT копируется и вставляется в чат вручную; прямого подключения нет.
- Не реализованы: фото прогресса, напоминания (нужен сервер), единицы длины (только см).
- Рекомендации по питанию и уходу — ориентировочные, не заменяют врача или дерматолога.
